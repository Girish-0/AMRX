# Decision records

Use an Architecture Decision Record (ADR) when a choice changes the baseline, interface, evidence policy or development workflow.

| Record | Status | Decision |
|---|---|---|
| [0001](0001-current-baseline-and-history.md) | Accepted for repository organization | Preserve source history and identify v2 as the current development baseline |

For a new record, copy the [template](template.md), choose the next four-digit number and propose it in a PR. Do not mark a technical decision accepted without the relevant maintainer/domain review.
