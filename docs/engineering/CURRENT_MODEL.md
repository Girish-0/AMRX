## What the model establishes

The public viewer provides access to the CAD concept. A model view does not establish structural capacity, simulation validity, manufacturability, a built prototype, or test results. No native editable model archive or reproducible solver study has been committed to this repository.

The [v2 engineering roadmap](roadmap-v2.md) remains the documented development plan. Its targets must be reconciled against the V8 geometry during configuration review; a higher model version number does not automatically close a verification gate.

## Review path
