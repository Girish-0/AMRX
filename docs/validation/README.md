# Validation evidence

No physical test or reproducible solver evidence was supplied in this snapshot. This directory defines the record format for future work; templates are not completed tests.

For each result, record:

1. Gate and issue, configuration revision, author/reviewer and date.
2. Target/requirement and acceptance criterion agreed before the test.
3. Method, fixture or solver setup, units and applicable limits.
4. Raw files and hashes, transformations/scripts, results and uncertainty.
5. Pass/fail/inconclusive disposition, anomalies and follow-up.

Start with the [test record template](test-record-template.md). Link a reviewed record from the corresponding issue and status page when evidence exists. Preserve failed and inconclusive results alongside successful ones. A scaled polymer test does not establish full-scale metal capacity.

Archive large datasets with a stable access link and checksum. Never close a gate solely on a presentation image or a documentation PR.
